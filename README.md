# ComfyUI H3 Prompt Maker

MiniMax H3 (비디오+오디오 옴니모달 모델) 전용 **프롬프트 생성 커스텀 노드**입니다.
장면 요청(한국어 가능)과 참조 이미지를 넣으면 LLM이 H3 공식 포맷
(T2VA / I2VA / FL2VA / L2VA / Ref2VA)의 영어 프롬프트를 설계하고,
결과를 **같은 워크플로우의 H3 노드에 바로 와이어로 연결**할 수 있습니다.

[H3 Prompt Maker 웹앱](https://github.com/ssain3d-lgtm/minimax-h3-prompt-maker-google-studio-ai-v3)의
`prompts.ts`를 단일 원본으로 사용합니다. 기본은 속도용 **Fast 프로필**이고, 필요하면 전체
가이드가 담긴 **Full 프로필**로 되돌릴 수 있습니다.

## 속도 최적화 기본값

- **Fast 시스템 프롬프트**: 출력 계약·정체성·샷 타이밍·카메라·사운드 핵심 규칙은 유지하면서
  실제 전송 길이를 33,179자에서 7,104자로 줄였습니다(약 79% 감소). 입력 프리필 시간이 줄어듭니다.
- **thinking `off`**: Qwen3 계열의 긴 사고 출력을 기본으로 막습니다. 필요하면 설정에서 `auto`/`on` 선택 가능.
- **모델은 창을 닫을 때 언로드**: 같은 창에서 다시 생성할 때는 모델을 계속 써서 재로딩을 피하고,
  적용·닫기·Esc 후에는 LM Studio/Ollama에 명시적으로 언로드를 요청합니다.
- **LLM 전송 이미지 최적화**: ComfyUI 로컬 모델에 보내는 복사본만 최대 1280px JPEG로 줄입니다.
  첨부 원본과 히스토리 원본은 그대로 보존됩니다.
- **실시간 스트리밍/중단**: 로컬 HTTP 모델의 생성 결과를 바로 표시하고, 중단·창 닫기는 실행 중인
  업스트림 스트림까지 닫습니다. 모델 준비·첫 토큰·생성·전체 시간과 토큰 수/tok/s도 표시합니다
  (서버가 usage를 제공하는 항목만).

`max_tokens`는 자동으로 줄이지 않으며 기존 기본값 **60000**을 그대로 유지합니다.

## 노드

### 🖥️ MiniMax H3 Prompt Maker (UI)
**웹앱 UI를 ComfyUI 위에 그대로 띄우는 노드.** 노드에는 버튼 두 개뿐입니다.

| 버튼 | 하는 일 |
|---|---|
| 🎬 프롬프트 메이커 열기 | 웹앱 화면 전체를 오버레이로 엽니다 — 세부 모드·길이·SFW/NSFW·장면 요청·대사·목소리·카메라·리메이크 모드·참조 첨부·오디오 트림·히스토리 전부 동일 |
| ⚙️ 모델 연결 | 백엔드 / 주소 / 모델 / 키 / temperature / Fast·Full / thinking / 생성 후 / max_tokens. **이 노드가 직접 설정하는 것은 이것뿐입니다** |

**⚙️ 모델 연결 다이얼로그**

1. 백엔드를 고르면 표준 주소가 자동으로 채워지고, 그 백엔드가 쓰지 않는 칸은 숨겨집니다
   (HTTP 서버에는 CLI 명령이, CLI 백엔드에는 주소·모델 목록이 없습니다).
2. **🔌 연결 확인** — 실제로 서버에 닿아 봅니다. 성공하면 **`● 연결됨 — 모델 N개 확인됨`**,
   실패하면 빨간 글씨로 이유가 그대로 나옵니다 (주소 오타 / 서버 꺼짐 / 키 오류).
   생성할 때가 아니라 **여기서** 알 수 있다는 게 요점입니다.
3. 확인에 성공하면 **모델 목록이 실제 서버 응답으로 채워집니다.**
4. **모델 로드** — 고른 모델을 서버 메모리에 미리 올립니다. LM Studio·Ollama·vLLM은 첫 요청
   때 모델을 로드하는데, 그 지연이 길어서 첫 생성이 멈춘 것처럼 보입니다. 미리 눌러 두세요.
5. **언로드** — 고른 모델의 VRAM을 바로 비웁니다(LM Studio/Ollama).
6. 주소·키를 다시 건드리면 확인 상태가 해제됩니다 — 확인하지 않은 설정이 확인된 것처럼
   보이지 않게 하기 위함입니다.

**프롬프트 프로필 (기본 Fast)**

| 값 | 동작 |
|---|---|
| `Fast` | 렌더에 필요한 핵심 계약만 전송 — Qwen3.8 27B 같은 로컬 모델의 입력 처리 속도 우선 |
| `Full` | 전체 H3 참조 가이드 전송 — 규칙 디버깅이나 Fast 결과가 부족할 때 |

**thinking (기본 off)** — 추론 모델의 사고를 켜고 끕니다.

| 값 | 동작 |
|---|---|
| `auto` | 모델 기본값에 맡김 |
| `off` | 사고를 끄고 **예산 전부를 답변에** — 한 줄만 돌아오는 증상의 직접적인 해법 |
| `on` | 사고를 강제로 켬 |

`/no_think` 토큰과 `chat_template_kwargs`(vLLM·최신 LM Studio)를 함께 보냅니다.
후자를 모르는 서버가 요청을 거부하면 그 필드만 빼고 자동으로 다시 보내므로,
어느 백엔드에서도 안전합니다. CLI 백엔드는 토큰만 붙습니다.

**max_tokens (기본 60000)** — 응답 상한입니다. 이번 최적화에서는 값이나 계산 방식을 바꾸지
않았습니다. 추론을 `on`으로 켜면 Qwen3 계열이 이 예산 일부를 사고에 사용할 수 있으며,
너무 낮추면 본문이 잘릴 수 있습니다.

사고 블록 안에 본문을 다 써버린 경우는 앱이 알아서 그 안의 프롬프트를 꺼내 씁니다.

**생성 후 (기본 창 닫을 때 언로드)** — 모델을 VRAM에 언제까지 둘지 정합니다.

| 값 | 동작 |
|---|---|
| `유지` | 서버 기본값 그대로 — 모델이 계속 올라가 있어 다음 생성이 즉시 시작됨 |
| `창 닫을 때 언로드` | **기본값.** 창 안에서 재생성할 때는 유지하고, 적용·닫기·Esc 시 명시적으로 언로드 |
| `5분 유지` | 5분 뒤 언로드. 연달아 몇 장 뽑을 때 로딩을 다시 기다리지 않으면서 VRAM도 물고 있지 않음 |
| `즉시 언로드` | 응답 직후 내려서 VRAM을 비움 — 매 생성마다 다음 재로드가 필요 |

내려간 뒤에도 **프롬프트 생성을 누르면 마지막에 고른 모델이 자동으로 다시 올라갑니다.**
따로 '모델 로드'를 누를 필요는 없고, 모델을 디스크에서 올리는 시간만큼 첫 요청이 느려집니다.

LM Studio 0.4 이상에서는 재로드와 명시적 언로드를 각각 공식
`/api/v1/models/load`·`/api/v1/models/unload` 엔드포인트로 처리합니다. 따라서 JIT가 꺼져 있거나
서버 화면에서 수동으로 올린 모델도 `창 닫을 때` 또는 `즉시 언로드`하면 실제로 VRAM에서 내려갑니다. 이전의 `ttl`
방식은 LM Studio 공식 문서상 **JIT로 로드된 모델에만 적용**되어 수동 로드 모델을 내리지 못했습니다.
구버전 LM Studio에서는 기존 1토큰 JIT 로드와 `ttl` 방식으로 자동 폴백합니다.

`5분 유지`는 LM Studio의 `ttl`, Ollama의 `keep_alive`를 각각 해당 백엔드에만 보냅니다.
LM Studio에서 서버 화면이나 `lms load`로 직접 올린 모델은 기존 TTL이 없을 수 있으므로 5분 설정이
소급 적용되지 않습니다. 확실히 VRAM을 비우려면 `언로드` 버튼이나 `창 닫을 때`를 사용하세요.
llama.cpp·vLLM은 프로세스가 모델을 소유하므로 이 드롭다운으로 언로드되지 않습니다.

업데이트 전에 저장된 UI 노드는 처음 열 때 한 번 `auto → off`, `즉시 언로드 → 창 닫을 때`,
`Fast`로 마이그레이션됩니다. 그 뒤 사용자가 다시 고른 값은 그대로 보존됩니다.

## 비디오와 오디오가 로컬 모델에 닿는 방식

로컬 백엔드가 쓰는 OpenAI 호환 채팅 스키마에는 **비디오 파트가 없습니다.** 그래서 클립은
프레임을 뽑아 **타임스탬프가 찍힌 시트 한 장**으로 합쳐 이미지처럼 실려 갑니다 (클립당 한 장).
오버레이의 비디오 타일에서 `🎞 모델이 보는 8프레임` 을 누르면 모델이 받는 그림 그대로 보입니다.

- 기본 **8장** — 15초 기준 1.9초에 한 장. 카메라 패스·동작 궤적·페이싱을 읽기에 충분합니다.
  4 / 8 / 16 / 24 중에서 고를 수 있고, 24장은 칸이 256px까지 줄어 얼굴이 흐려집니다.
- 시트는 **참조 사진 뒤에** 붙고 자체 상한(3장)을 가집니다 — 클립을 세 개 붙여도
  `<Picture 9>`를 밀어내지 않습니다.
- CLI 백엔드는 stdin만 받으므로 사진도 시트도 갈 수 없습니다. 메모만 전달됩니다.

**오디오는 옴니 모델만 듣습니다.** LM Studio는 전달 서버일 뿐이라, LM Studio를 쓰더라도 로드한
모델 자체가 오디오 입력을 지원해야 합니다. 텍스트 모델(Qwen3 계열 포함)과 일반 비전 모델에는 오디오
인코더가 없습니다. 실제로 들으려면 Qwen2-Audio · Qwen2.5-Omni · Qwen3-Omni 같은 모델이어야
합니다. 오버레이는 일단 `input_audio` 파트로 보내고, 서버가 거부하면 **오디오만** 빼고 한 번
다시 보냅니다 (사진은 그대로 남습니다). 그리고 "듣지 못했으면 그 클립에 대해 아무 말도 하지
말라"는 지시가 함께 가므로, 못 들은 소리를 지어내지 않습니다.

노드 얼굴에 연결 상태가 한 줄로 남습니다: `● lmstudio · qwen3-14b-instruct`
(● = 연결 확인됨, ○ = 저장만 됨).

오버레이에서 생성한 뒤 **'이 노드에 적용'** 을 누르면 결과가 노드 출력
(`prompt` / `length_frames` / `korean_summary` / `all_segments` / `segment_count`)으로 나갑니다.
Queue를 눌러도 LLM을 다시 호출하지 않습니다 — 눈으로 확인하고 승인한 프롬프트만 렌더에 들어갑니다.
아직 적용한 게 없으면 실행이 그 사실을 말하며 멈춥니다.

알아두실 점:

- **참조 미디어는 워크플로우에 저장되지 않습니다.** ComfyUI 워크플로우는 그 워크플로우로 만든
  모든 PNG 메타데이터에 통째로 들어가므로, 10MB 오디오를 넣으면 출력 이미지마다 따라다닙니다.
  워크플로우에는 장면·설정 텍스트만 들어갑니다.
- 대신 **첨부는 브라우저 IndexedDB에 히스토리별로 남습니다.** 오버레이 하단 히스토리 카드를
  누르면 그때 쓴 이미지·비디오·오디오와 역할 메모가 그대로 돌아옵니다 (ComfyUI를 껐다 켜도 유지).
  목표 총량 500MB(또는 브라우저가 허용한 저장공간의 80% 중 작은 값)를 넘으면 오래된 것부터 비워집니다.
- **마스크 → AI 인페인팅은 없습니다.** Gemini 이미지 모델 전용 기능이라 로컬 LLM으로 대체할 수 없습니다.
  ComfyUI의 인페인트 노드를 그래프에서 쓰세요.
- 오버레이는 **완전 오프라인**입니다. Tailwind를 CDN이 아니라 빌드된 CSS로 싣습니다.
- 원본 사진은 보존하고, **로컬 LLM 요청에 실리는 이미지 복사본만** 긴 변 1280px·JPEG 품질 0.86으로
  줄입니다. 이미 작은 JPEG나 변환 시 오히려 커지는 파일은 원본 복사본을 그대로 보냅니다.

아래 두 노드는 그래프에 직접 와이어링하고 싶을 때 쓰는 위젯 방식입니다. UI 노드와 같은
시스템 프롬프트·같은 출력 5개를 냅니다.

### 🎬 MiniMax H3 Prompt Architect
장면 요청 → 완성된 H3 프롬프트.

| 출력 | 용도 |
|---|---|
| `prompt` (STRING) | H3 텍스트 인코딩 노드에 연결 — **이번 렌더 한 개분**(분할 생성 시 세그먼트 1) |
| `length_frames` (INT) | H3 length/frames 입력에 연결 — `prompt`와 항상 짝이 맞음 |
| `korean_summary` (STRING) | 한국어 요약 (모델이 제공한 경우) |
| `all_segments` (STRING) | 분할 생성 시 전체 시퀀스(헤더 포함). 단일 렌더면 `prompt`와 동일 |
| `segment_count` (INT) | 세그먼트 개수 (단일 렌더 = 1) |

코드펜스·`length` 라인·추론(`<think>`) 블록은 자동으로 제거되어 `prompt`는 붙여넣기 가능한 상태로 나옵니다.

주요 입력: 장면 요청 · 세부모드(ref2va/t2va/i2va/fl2va/l2va) · 길이 프리셋 ·
SFW/NSFW · 참조 이미지(IMAGE, 최대 9장 — `<Picture N>` 라벨 자동 부여) ·
대사 · **화자 목소리 묘사** · 카메라 지정 · 비디오/오디오 참조 메모 · 커스텀 지침 ·
프롬프트 프로필(Fast/Full).

### 🔄 MiniMax H3 Prompt Remake
기존 프롬프트를 "유사하지만 다른 느낌"으로 변주.

- **소스 종류**: `h3_output`(이전 H3 결과물 — 구조·정체성 문구 잠금) /
  `user_written`(직접 작성·외부 프롬프트 — 분석 후 H3 형식으로 재구성)
- **변경 축** 토글 7종: 분위기/조명 · 장소/배경 · 의상 · 카메라 문법 · 시간대/계절 · 사운드/음악 · 전체 톤
- **강도**: subtle / medium / reimagine

## LLM 백엔드

`backend` 드롭다운에서 고르면 표준 주소/명령이 자동으로 적용됩니다
(ComfyUI-LLM-Hub와 같은 방식). 대부분의 경우 **백엔드만 고르고 `server_model`
드롭다운에서 모델을 선택**하면 끝입니다.

### 로컬 HTTP 서버 (프리셋 — base_url 입력 불필요)

| backend | 자동 주소 | 비고 |
|---|---|---|
| `lmstudio` | `http://127.0.0.1:1234/v1` | 기본값. 서버 켜고 브라우저 새로고침하면 `server_model`에 모델 목록이 뜸 |
| `ollama` | `http://127.0.0.1:11434/v1` | |
| `llamacpp` | `http://127.0.0.1:8080/v1` | `llama-server` 기준. `llama-cli` 단발 실행은 매번 모델을 리로드하므로 비추천 |
| `vllm` | `http://127.0.0.1:8000/v1` | |

- **`server_model` 드롭다운**: 위 표준 포트에 떠 있는 서버들의 모델 목록을 자동 조회합니다
  (내 컴퓨터 loopback만 조회 — 원격/유료 주소는 건드리지 않음). `(auto)` = `model` 칸의 값 사용.
  서버를 켠 뒤 브라우저를 새로고침하면 목록이 갱신됩니다.
- 참조 이미지는 **비전 모델**(Qwen-VL, Gemma 3 비전 등)을 로드했을 때만 LLM이 직접 봅니다.
  비전 미지원 모델이면 자동으로 텍스트 전용으로 재시도합니다 (`send_images_to_llm` 끄기 가능).
- 권장 로컬 모델: **Qwen3 14B 이상 인스트럭트** — 형식 준수가 빡빡해서 8B 이하는 자주 깨집니다.
- `api_key`를 비워 두면 환경변수(`OPENAI_API_KEY` / `OPENROUTER_API_KEY` / `GEMINI_API_KEY` / `H3_LLM_API_KEY`)를 사용합니다.
  **위젯에 직접 입력한 키는 워크플로우 JSON과 그 워크플로우로 만든 모든 PNG 메타데이터에 저장되므로**, 공유할 계획이면 환경변수를 쓰세요.

### `gemini` — Google Gemini API (프리셋, 웹앱이 쓰던 구글 모델)

| backend | 자동 주소 | 비고 |
|---|---|---|
| `gemini` | `https://generativelanguage.googleapis.com/v1beta/openai` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료 발급한 API 키 필요 |

원래 웹앱이 Google AI Studio에서 호출하던 바로 그 Gemini 모델을, 같은 UI 그대로 씁니다.

1. ⚙️ 모델 연결에서 백엔드를 `gemini`로 — 주소가 자동으로 채워집니다.
2. API 키를 칸에 넣거나, ComfyUI를 띄우는 셸에서 `GEMINI_API_KEY`(또는 `GOOGLE_API_KEY`)로
   export 해두세요. 이 프리셋의 주소는 구글 고정 호스트라서 환경변수 키가
   `H3_LLM_ALLOWED_HOSTS` 등록 없이도 전송됩니다 (다른 원격 주소로는 여전히 나가지 않고,
   구글 호스트에는 `OPENAI_API_KEY`가 아니라 Gemini 키만 갑니다).
3. **🔌 연결 확인** — 계정에서 쓸 수 있는 Gemini/Gemma 채팅 모델 목록이 **구글 라이브 목록 그대로** 뜹니다
   (구글의 네이티브 모델 API에서 `generateContent` 지원 모델만, 전체 페이지; 임베딩·이미지·TTS·Live 모델은 제외).
   상태 줄에 `(auto) = gemini-3.6-flash`처럼 **(auto)가 실제로 쓸 모델**이 함께 표시됩니다.
4. 모델은 **(auto)로 두는 것을 권장**합니다 — 생성 때마다 라이브 목록에서 **최신 안정 Flash**
   (`gemini-N-flash`, 프리뷰·lite 제외)를 고르므로 구글이 세대를 교체해도 계속 동작합니다.
   2026-06-17에 `gemini-2.5-flash`/`2.5-pro`가 종료되면서 고정 기본값이 404로 죽었던 것이 이 방식으로 바꾼 이유입니다.

무료 등급(2026-09 기준, `gemini-3.6-flash`): **분당 10회 / 일 1,500회**. Pro 계열은 무료 등급이 없습니다(limit 0).
한도는 프로젝트별로 다를 수 있으니 [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)에서 본인 값을 확인하세요.

**오류가 나면 화면에 구글의 응답 본문과 원인 안내가 그대로 뜹니다** (구글 고정 호스트라서 본문을 가리지 않습니다):

| 구글 응답 | 뜻 | 조치 |
|---|---|---|
| 404 `NOT_FOUND` | 모델 ID가 종료·폐기됨 | 🔌 연결 확인 후 목록에서 다시 선택, 또는 (auto) |
| 429 `limit: 0` | 그 모델은 무료 등급 없음 | Flash 계열로 변경 또는 결제 활성화 |
| 429 `PerDay` | 일일 무료 한도 소진 | 내일 재시도 / 결제 |
| 429 (그 외) | 분당 한도(10회) 초과 | 잠시 후 재시도, Queue 연타 자제 |
| 400 `API key not valid` | 키 오류 | https://aistudio.google.com/apikey 에서 재발급 |
| 403 | 키 권한·지역 | AI Studio 키인지, 무료 등급 지원 지역인지 확인 |

알아두실 점:

- 참조 이미지는 비전을 기본 지원하는 Gemini에 그대로 전달됩니다. 오디오 클립은 옴니 입력을
  받는 모델에서만 들리고, 거부되면 오디오만 빼고 자동 재시도합니다 (로컬 백엔드와 동일한 규약).
- **thinking**: `off`/`on`은 Gemini에는 `/no_think` 토큰 대신 `reasoning_effort`(low/high)로
  전달됩니다. 현행 3.x 모델은 사고를 완전히 끌 수 없어 `low`가 "최소 사고"이고, 필드 자체를
  거부하는 모델이면 그 필드만 빼고 자동 재시도합니다.
- **안전 필터**: 요청에 AI Studio의 "안전 설정 끔"과 같은 `safety_settings: BLOCK_NONE`을 함께 보냅니다.
  그래도 구글의 고정 필터(미성년·불법 콘텐츠 등)에 걸리면 본문 없이 `finish_reason=content_filter`로
  끝나는데, 이때 화면에 "안전 필터가 응답을 막았습니다"라고 원인이 표시됩니다 — 장면·대사 표현을
  완화하거나 참조 사진을 바꾸세요. 같은 자리에 `finish_reason=length`가 뜨면 토큰 한도 문제입니다.
- **max_tokens**: 기본 60000이 해당 모델의 출력 상한보다 크면 구글이 거부하는데, 그 경우
  자동으로 상한 없이(모델 최대치) 다시 보냅니다.
- **생성 후**(언로드)와 **모델 로드**는 클라우드 API에 해당 없음 — gemini에서는 숨겨집니다.
- 무료 등급은 분당/일일 요청 한도가 있습니다: [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)

### CLI 백엔드 (구독 CLI 모델)

전체 프롬프트를 stdin으로 넘기고 stdout을 결과로 사용합니다. `cli_command`를
비우면 프리셋 명령이 쓰입니다:

| backend | 기본 명령 | 비고 |
|---|---|---|
| `claude_cli` | `claude -p --output-format text` | API 키 없이 구독으로 처리 |
| `gemini_cli` | `gemini -p` | 구글 계정/구독으로 처리 |
| `codex_cli` | `codex exec` | |
| `custom_cli` | (직접 입력 필수) | stdin→stdout 규약만 지키면 어떤 CLI든 가능 |

CLI 방식은 프로세스 기동 오버헤드 때문에 HTTP 서버 방식보다 호출당 수 초 느리고,
이미지 전달은 지원하지 않습니다(텍스트 전용).

**CLI 백엔드로 실행되는 명령은 요청 본문에서 오지 않습니다.** 이 라우트는 ComfyUI 서버 위에
얹혀 있고 ComfyUI에는 자체 인증이 없습니다. 즉 POST 본문도, 남이 공유한 워크플로우에 저장된
위젯 값도 신뢰할 수 없는 입력입니다. `shell=False`는 파이프·`;`·`$()` 체이닝만 막을 뿐,
`sh -c "..."` 처럼 인터프리터를 직접 지목하는 것은 막지 못합니다.

그래서 실제로 실행되는 명령은 여기서 고정됩니다:

- **프리셋** (`claude_cli` / `gemini_cli` / `codex_cli`) — 사용자가 직접 설치하고 이름으로 고른
  명령이므로 설정 없이 그대로 동작합니다. 본문 값으로 덮어쓸 수 없습니다.
- **사용자 지정 CLI** — 환경변수 `H3_CLI_COMMAND` 에 넣은 값만 씁니다. ComfyUI를 띄우는 셸에서
  `export H3_CLI_COMMAND='my-runner --stdin'` 처럼 지정하세요. 설정창에 적은 값은 무시됩니다.

같은 이유로 **환경변수에 있는 API 키는 아무 주소로나 나가지 않습니다.** `base_url`도 요청
본문에서 오기 때문입니다. `OPENAI_API_KEY` 등은 루프백 주소, 또는 `H3_LLM_ALLOWED_HOSTS`
(쉼표 구분)에 적어둔 호스트로만 전송됩니다. 설정창에 직접 입력한 키는 그 주소를 쓰겠다는
사용자의 선택이므로 그대로 전송됩니다. 원격 서버가 돌려준 오류 본문도 호출자에게 되돌려주지
않고 ComfyUI 콘솔에만 남깁니다 — 그러지 않으면 이 라우트가 ComfyUI가 닿을 수 있는 모든 곳을
읽어오는 통로가 됩니다.

## 웹앱과 동기화

이 저장소는 웹앱에서 두 가지를 그대로 가져옵니다 — 시스템 프롬프트(`h3_prompts.py`)와
오버레이 UI(`web/app/`). 둘 다 **생성물이고 커밋되어 있습니다**(사용자가 npm을 돌릴 필요 없음).
웹앱이 바뀌면 손으로 고치지 말고 재생성하세요:

```bash
python3 tools/sync_app.py /path/to/minimax-h3-prompt-maker-google-studio-ai-v3
```

프롬프트 추출 → 오버레이 빌드 → `web/app/` 교체를 한 번에 하고, 번들에 CDN 참조가
남아 있으면 실패합니다.

## 테스트

```bash
python3 tests/test_parse.py     # 출력 파서 회귀 (INT 출력이 H3 샘플러로 직결됨)
python3 tests/test_routes.py    # 오버레이 HTTP 계층 — 경로 탈출 차단, 요청 번역
python3 tests/test_system_prompt.py  # H3 시스템 프롬프트가 실제 요청에 실리는지 (가짜 LLM 서버로 본문 캡처)
python3 tests/test_thinking.py       # thinking 모드가 실제 요청에 실리는지 + 거부 서버 폴백
python3 tests/test_media_parts.py    # 시트·오디오의 실제 요청 바디와 거부 시 벗겨내는 순서
python3 tests/test_unload_reload.py  # 언로드 → 다음 생성 때 재로드까지의 왕복
python3 tests/test_streaming.py      # SSE 조립·사용량 지표·업스트림 취소
python3 tests/test_stream_route.py   # aiohttp → 브라우저 NDJSON 전체 경로
python3 tests/test_fast_profile.py   # Fast 계약 유지와 Full 대비 크기
python3 tests/test_event_loop.py     # 느린 생성 중 ComfyUI 이벤트 루프 응답성(aiohttp 필요)
python3 tools/check_bundle.py   # 커밋된 번들이 서빙 가능하고 외부 참조가 없는지
```

`_parse_llm_output`은 이 노드팩에서 유일하게 순수하면서 잘 깨지는 함수이고,
INT 출력이 H3 샘플러로 직결되므로 출력 형태별 회귀 테스트를 고정해 두었습니다.
라우트 쪽은 ComfyUI 서버에 얹히는데 ComfyUI에는 자체 인증이 없으므로,
호출자가 준 문자열이 파일 시스템에 닿는 유일한 지점(정적 파일 핸들러)을 특히 고정해 두었습니다.

## 팁

- `seed`는 캐시 무효화용입니다 — 같은 입력으로 다른 변주를 뽑고 싶으면 seed만 바꾸세요
  (기본값이 생성마다 자동 변경).
- Ref2VA에서 인물 사진을 `images`에 연결하면 `<Picture 1>`이 정체성 앵커가 됩니다.
  같은 이미지를 H3 레퍼런스 입력에도 연결하세요.
- SFW 모드는 전연령 유지 지시가, NSFW 모드는 무검열 지시가 시스템 프롬프트에 들어갑니다.
  실제 수위는 사용하는 LLM의 정책을 따릅니다.
